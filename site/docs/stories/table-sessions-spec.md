# Table Sessions — Detailed Spec

**Epic:** E5 — Guest Ordering Flow / E8 — Staff Dashboard  
**Last Updated:** April 2026

---

## What Is a Table Session?

A **table session** is the life of one group of guests at a table — from the moment the first person scans the QR code to the moment staff marks the table as paid and free.

During one table session, multiple guests can scan the same QR code and each place their own orders independently. All their orders are grouped together under the same session. Staff can see all orders for the table in one combined view, and the total shown at checkout is the combined total of every guest at that table.

---

## Guest Experience

### Arriving at the Table

Each guest scans the QR code on the table with their phone. No app download is required — the menu opens instantly in the browser.

The first guest to scan opens the session automatically. Every other guest who scans the same code before the table is closed joins the same session. Guests do not need to coordinate with each other — the system handles everything automatically. Each guest sees the full menu and adds items to their own cart independently.

### Ordering

Each guest places their own order normally. From the kitchen's perspective, it does not matter whether one guest or six guests ordered — all orders appear together under the table.

Guests can continue to place additional orders throughout their visit, for example ordering dessert after finishing the main course. Each new order is added to the running session.

### Tracking Order Status

Each guest can see the status of their own orders on their own phone. They are not shown the other guests' orders — only their own. This keeps things simple and avoids confusion when a large group is seated.

---

## Staff Experience

### Viewing the Table

When a staff member taps on an occupied table in the floor view, they see all orders for that session grouped together — regardless of how many guests placed them.

The table view shows:

- Each order and its items, with status: pending / preparing / ready / served
- A running total for the session so far
- How many separate orders have been placed at the table

### Closing the Table

When the guests are ready to pay, the staff member marks all items as served (or confirms that everything is settled) and taps **Close Table**.

What happens next:

- The session is finalised with a total amount
- The table immediately shows as **free** on the floor view
- The QR code is ready for the next group of guests — no reset or admin action needed
- The closed session's data remains in the daily report

---

## Take-Away Sessions

A take-away order works almost identically to a table session, but without a physical table or QR code scan.

A take-away guest accesses the menu directly, for example via a link or a counter-mounted QR code. They browse, order, and receive a status update the same way as a dine-in guest.

The key differences from a table session are:

- No table is assigned
- No other guests can join the session — each take-away order is its own session
- The session closes automatically once all items are marked served

Take-away sessions appear in the daily report alongside dine-in tables.

---

## Key Rules

- A table can only have one **open** session at a time
- Closing a table session does not delete any data — it only marks the session as complete
- If a QR code is regenerated by the owner, any open session on that table is not affected — only future scans use the new code
- Staff can only close a session for tables assigned to them, unless the owner has granted all-tables access
